Locked

Only admins manage this server. Enter the host key (config\host-key.txt on the server PC), or open Manage games from the launcher while signed in to an admin account.

Upload a game

Each upload gets its own place ID, kept for good: saves and thumbnails stay with it, and the ID is never given to another game. Places from a newer Roblox Studio are converted for the 2017 engine on the way in (save them as .rbxlx).


    


    

      
Join code for players

      
One code gets new players in: they paste it into their launcher, which sets up Tailscale and connects them to this server only. No Tailscale account or invite needed. First make a Tailscale auth key for players (README-SERVER.txt, "Join codes"). The code contains that key, so share it only with your players; make a new key and code to cut off old ones.

      

        
        
        

          
          
          
        

      

      

    


    

      

        
Announcements

        
      

      
Shown in every player's launcher (1.5.2 and newer) within a few minutes, until it expires or you remove it. Players can dismiss one; an important one also pops up when it arrives.

      

        
        
        
        
        

          
          
        

      

      

    


    

      

        
Server

        
      

      
Updates to this server's own files come from the project and install by themselves once nobody has played for a few minutes: players are saved first, the old files are kept, and they are put back if the new version does not start. Games, accounts, saves and settings are never touched. Changes need the host key.

Studio accounts

        
      

      
People log in to Roblox Studio with these (Studio is in the Studio folder; its start page lists this server's games). The first login with a name creates the account. Admins may open and publish over every game; everyone else edits only the games they published and the ones whose owner added them as editors. To reset a forgotten password, delete the account: the next login with that name makes it again. The first account made on this PC is an admin.

Missing assets

        
      

      
Roblox no longer hands these out: most sounds became private in its 2022 audio privacy change, others were removed for copyright or moderated. Upload a replacement and the server uses it from then on: an OGG, MP3 or WAV for a sound, a PNG or JPG for an image, a .rbxm or .rbxmx for an animation exported from Studio.
